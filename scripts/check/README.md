# Проверки после правок index.html и скриптов

**Всё разом:** `VERIFY_CODE=… sh scripts/check/run-all.sh` — сам поднимает сервер (порт 8799), печатает ✓/✗ по трём проверкам, код возврата 1 при провале. Его же вызывает `.githooks/pre-commit` на коммитах `index.html`/`wb-secure.js`, если `VERIFY_CODE` задан.

CI нет — эти три прогона заменяют его. Запускать из корня репозитория, страница должна отдаваться
статическим сервером, код доступа — только через переменную окружения (в файлы его не писать).

```
python3 -m http.server 8765 --bind 127.0.0.1 &          # из корня репозитория
export VERIFY_CODE='<код доступа из чата>'
node scripts/check/tabs-smoke.cjs     # все вкладки × площадки: ошибок консоли 0, ни одной пустой панели
node scripts/check/ozon-profit.cjs    # прибыль Ozon 01–14.10 / сентябрь / август, mpBad 0, errors []
node scripts/decrypt.cjs "$VERIFY_CODE" && node scripts/check/full-trucks.cjs   # машины: браузер = скрипт
```

- `tabs-smoke.cjs` (`PORT`, по умолчанию 8765) — печатает строку на каждую пару вкладка × площадка и `ERRORS N`.
  Цель — `ERRORS 0`; длина текста панели около нуля — признак сломанного рендера.
- `ozon-profit.cjs` (`URL`) — сводка прибыли Ozon из `ozFinRows`. **`oct` — это 01–14.10, окно зашито в скрипте**
  (первые дни с отчётом «Оплата за заказ»): `oct.ad` = `xw` + `fee` = 1 242 047 ₽, `profit` 2 840 276 ₽ — обязаны
  не меняться; `sep`/`aug` — до рубля прежние (ЖУРНАЛ.md). Октябрь целиком (на снимке 19.10: 01–18.10 прибыль
  3 615 841 ₽) скрипт не печатает. `mpBad` — строки, где `mpFee ≠ выручка × фикс. ставка + реклама`, должно быть 0.
  `feeOutside` — строки с фактом отчёта ВНЕ 01–14.10: после заливки отчётов за 15.10 и позже это не 0 (снимок 19.10 —
  282), это норма, а не ошибка.
- `full-trucks.cjs` (`URL`, `OUT_DIR`) — подсорт по правилам с 27.10.2026 (ЗАП-08/11/13): каждая машина ровно 33 паллеты
  и ≤ 6 кодов, добор только при базе ≥ 20 паллет и только до 240 дн запаса, «не едет» = паллеты отказавших машин по
  направлению, склад не уходит в минус, `browser≠script: 0` (дашборд и `scripts/resupply-report.cjs` совпадают по
  каждому коду, складу и направлению: `oMsk` / `oKzn` / `wFbo`), модульные тесты `truckFill(rows,p,t)`, выгрузка на
  трёх площадках. Нужен расшифрованный `decrypted/wb-data.js`. Замер 27.10: 12 машин, нарушений 0.
