# WB · РНП Дашборд

Управленческий дашборд для Wildberries в формате сайта (один HTML-файл).
Показывает динамику заказов и выкупов, выручку и валовую прибыль, юнит-экономику,
оборачиваемость и ДРР — в виде отчёта о прибылях и продажах (РНП).

Данные считаются **прямо в браузере** и никуда не отправляются.

## Как открыть

- **Локально:** дважды кликнуть по `index.html` — откроется в браузере.
- **Как сайт:** залить на любой статический хостинг. Проще всего — **GitHub Pages**:
  Settings → Pages → Source: ветка репозитория → папка `/root`. Через минуту
  дашборд будет доступен по ссылке вида `https://<логин>.github.io/dashboard/`.

Файл самодостаточный: стили, скрипты и демо-данные внутри. Внешняя сеть нужна
только для разбора `.xlsx` (подгружается парсер); `.csv` работает всегда, в т.ч. офлайн.

## Как обновлять данные — 3 способа

1. **Загрузить отчёт (основной способ).** Кнопка **«Загрузить отчёт»** → выбрать
   CSV или XLSX по шаблону. Дашборд пересчитается и сохранит данные в этом браузере
   (localStorage) — при следующем открытии они останутся.
2. **Прислать сырые выгрузки мне (Claude).** Скидываете отчёты из личного кабинета
   WB как есть (продажи/заказы, финансовый, остатки, реклама) — я привожу их к шаблону
   или прямо к данным дашборда.
3. **Править вручную в коде.** В `index.html` вверху скрипта есть объект `DEMO`
   с базовыми метриками по месяцам — можно менять цифры там.

### Шаблон загрузки

Кнопка **«Шаблон»** скачивает CSV нужного формата. Структура:

| Метрика | Янв | Фев | … |
|---|---|---|---|
| Заказы, шт | 1180 | 1340 | … |
| Выкуплено, шт | 860 | 995 | … |
| … | | | |

- Первая строка — названия периодов (месяцы/недели).
- Первый столбец — название метрики (распознаётся по ключевым словам, регистр не важен).
- Разделитель `;` или `,`; числа принимаются в формате `1 234,56` или `1234.56`.
- Пример готового файла: `sample-data/example-report.csv`.

Базовые (вводимые) метрики: `Заказы, шт` · `Выкуплено, шт` · `Возвраты, шт` ·
`Средняя цена продажи, ₽` · `Себестоимость за шт, ₽` · `Комиссия WB, ₽` ·
`Логистика, ₽` · `Хранение, ₽` · `Реклама, ₽` · `Налог, ₽` · `Остаток на складе, шт`.

Всё остальное дашборд считает сам.

## Что считается автоматически

| Показатель | Формула |
|---|---|
| Выручка | выкуплено × средняя цена |
| Себестоимость проданного | выкуплено × себестоимость за шт |
| % выкупа | выкуплено ÷ заказы |
| К перечислению от WB | выручка − комиссия − логистика − хранение |
| Валовая прибыль | выручка − комиссия − логистика − хранение − реклама − себестоимость − налог |
| Маржинальность | прибыль ÷ выручка |
| ДРР | реклама ÷ выручка |
| ROI | прибыль ÷ себестоимость |
| Оборачиваемость, дн | остаток ÷ (выкуплено ÷ 30) |
| Юнит-экономика | те же затраты в пересчёте на 1 проданный товар |

## Дальнейшие шаги (по желанию)

- **Автоматизация через API продавца WB** — дашборд сам подтягивает статистику по
  токену, без ручной выгрузки файлов. Требует небольшого backend и безопасного
  хранения токена; делается отдельным этапом поверх текущей версии.
- Разбивка по SKU/категориям, план-факт, сравнение периодов.

## Стек

Чистый HTML + CSS + JavaScript, без фреймворков и сборки. Графики — inline SVG.
Тёмная/светлая тема, адаптив под мобильные. Разбор XLSX — библиотека SheetJS
(подгружается по требованию).
