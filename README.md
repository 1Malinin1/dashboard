# WB · РНП Дашборд

Управленческий дашборд для Wildberries в формате сайта (один HTML-файл).
Пять вкладок: **Главная** (сводный P&L), **Динамика заказов**, **Оборачиваемость**
(с расчётом дозаказа), **Товар** (карточка товара и сравнение периодов) и
**Финансы** (отчёт о реализации по дням).

Все расчёты идут **прямо в браузере**, данные никуда не отправляются — то, что вы
загружаете, остаётся только в вашем браузере (IndexedDB/localStorage).

## Как открыть

- **Локально:** дважды кликнуть по `index.html` — откроется в браузере.
- **Как сайт:** залить на любой статический хостинг. Проще всего — **GitHub Pages**:
  Settings → Pages → Source: ветка репозитория → папка `/root`. Через минуту
  дашборд будет доступен по ссылке вида `https://<логин>.github.io/dashboard/`.

Файл самодостаточный: стили и скрипт внутри `index.html`. Внешняя сеть нужна только
для разбора `.xlsx`-отчётов (парсер SheetJS подгружается с CDN по требованию).

## Откуда берутся данные

1. **Каталог товаров и история заказов** (`wb-data.js`) — собирается из вашей личной
   таблицы учёта и файла себестоимости. Пересобирается целиком, когда вы присылаете
   новую выгрузку — это делается через Claude, не на сайте.
2. **Воронка продаж по дням** (вкладка «Товар») и **отчёт о реализации** (вкладка
   «Финансы») — загружаются **прямо на сайте**: перетащите `.xlsx`-файл(ы) из личного
   кабинета WB в область загрузки. Разбор идёт в фоновом потоке (Web Worker), поэтому
   страница не подвисает даже на больших файлах. Каждая загрузка добавляется к уже
   накопленным данным (совпадающие даты просто обновляются, не дублируются); хранится
   скользящее окно 90 дней.
   Дашборд сам отделяет ваши товары от остального кабинета — по совпадению «Артикул WB»
   с каталогом.

Если каталога (`wb-data.js`) нет — вкладки покажут пустое состояние вместо ошибки.

## Что считается автоматически

| Показатель (Главная) | Формула |
|---|---|
| Валовая прибыль | К перечислению от WB − Себестоимость проданного |
| Удержания WB | Выручка − К перечислению (все вычеты WB одной цифрой) |
| Маржинальность | Валовая прибыль ÷ Выручка |
| Себестоимость проданного | (продано − возвращено) × себестоимость за шт из каталога |

«К перечислению» и «Выручка» берутся напрямую из отчёта о реализации WB — это уже
чистые фактические суммы, без реконструкции по формуле. Если для товара не указана
себестоимость, дашборд явно предупреждает об этом баннером над таблицей и не прячет
это в цифрах молча.

Кроме P&L дашборд считает: % выкупа и динамику заказов в штуках и деньгах
(вкладка «Динамика»); прогноз дней до обнуления остатка и объём дозаказа с округлением
до контейнеров, с учётом уже едущих поставок (вкладка «Оборачиваемость»); сравнение
двух произвольных периодов по одному товару (вкладка «Товар»).

Заголовки всех таблиц кликабельны — сортировка по любому столбцу, повторный клик
меняет направление.

## Дальнейшие шаги (по желанию)

- **Реклама и налоги** — сейчас прибыль считается без вычета расходов на рекламу и
  налога (их пока негде взять). Как только появится источник данных — добавляются в
  формулу на Главной.
- **Автоматизация через API продавца WB** — дашборд сам подтягивает отчёты по токену,
  без ручной выгрузки файлов. Делается отдельным этапом поверх текущей версии.

## Стек

Чистый HTML + CSS + JavaScript, без фреймворков и сборки. Графики — inline SVG.
Тёмная/светлая тема, адаптив под мобильные. Разбор XLSX — SheetJS в Web Worker.
Данные пользователя — IndexedDB (отчёты) и localStorage (настройки, тема).
