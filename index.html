Загрузка отчёта о реализации

Отчёт WB «О реализации товаров» (по заказам или по выкупам — структура одинаковая) — загружайте прямо здесь, файл может весить сколько угодно, в чат его слать не нужно. Один файл может охватывать сразу несколько дней; данные накапливаются по датам внутри отчёта, ничего не затирается. Храним последние 90 дней.

Загрузка отчёта по рекламе (WB Продвижение)

Финансы → Продвижение → «История затрат» (экспорт .xlsx). Беру кампании, начинающиеся с «18+», и разношу расход по артикулам (последние цифры в названии кампании). Обновляет ДРР и итоговую прибыль на «Главной». Можно грузить частями/повторно — задвоения нет.
